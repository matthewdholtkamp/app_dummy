# 🌈 Rainbow Catch

A bright, touch-friendly mobile browser game. Drag the unicorn left and right to catch the falling stars, hearts, candy, and rainbows — and dodge the storm clouds!

- ⭐ Star — +10
- 💖 Heart — +15
- 🍭 Candy — +20
- 🌈 Rainbow — +30
- ⛈️ Storm cloud — costs a life (you have 3)

Built with React + Vite + TypeScript. No assets, no audio files — just emoji and Web Audio beeps. Mobile-first; safe-area aware; works great in iOS Safari.

## Run

```bash
npm install
npm run dev
```

Then open the printed local URL on your iPhone (same Wi-Fi as your computer). Add to Home Screen for a fullscreen, app-like experience.

## Build

```bash
npm run build
npm run preview
```
